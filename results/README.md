# results/

Files in this directory were generated by the offline phases of the original project, **from synthetic traces and a loopback mock upstream**. They are properties of generated data, not real-world rates. No file here contains output of a live model.

| file | what it is |
|---|---|
| `baseline_vs_new.png`, `eval_report.md`, `per_trace.csv`, `summary.json`, `demo_output.txt`, `example_outputs.txt` | Phase 1 detector evaluation on synthetic traces (dev/test seeds) and demo output |
| `smoke_traces.jsonl` | scripted output of the loopback mock upstream (model name "mock"), including scripted reasoning text; not real model output |
| `pytest_verbose.txt` | **historical** pytest output from the end of Phase 1 (87 tests) |
| `phase1_5/` | Phase 1.5 held-out evaluation outputs (metrics, per-trace outcomes, error analysis, results table, and a **historical** pytest summary from that phase: 102 tests) |

**Test counts.** The two pytest outputs above are snapshots of earlier phases, kept unchanged apart from a header line. The current suite is run with `python -m pytest -q` and is expected to give the count stated in the top-level `README.md`.

Files under `results/phase1_5/` and the Phase 1 files can be regenerated with `python -m floodlab.run_offline_demo` and the Phase 1.5 commands in `PHASE1_5_REPORT.md`; regenerated output may differ in timestamps and path strings. Licence: CC BY 4.0 (see `DATA_NOTICE.md`).
